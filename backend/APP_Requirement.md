# Project Requirements

This document lists all Python modules used in the project and their recommended installation versions.

## Core Web Framework
- **Flask** – `pip install Flask==3.0.2`
- **Flask-WTF** – `pip install Flask-WTF==1.2.1`
- **Flask-Cors** – `pip install Flask-Cors==4.0.0`

## Utilities
- **requests** – `pip install requests==2.32.3`
- **wikipedia** – `pip install wikipedia==1.4.0`
- **psutil** – `pip install psutil==6.0.0`
- **AppOpener** – `pip install AppOpener==1.7`

## Speech & Audio
- **SpeechRecognition** – `pip install SpeechRecognition==3.10.4`
- **pyttsx3** – `pip install pyttsx3==2.90`

## Machine Learning & Visualization
- **tensorflow** – `pip install tensorflow==2.20.0`
- **keras** – included with TensorFlow
- **matplotlib** – `pip install matplotlib==3.9.2`
- **numpy** – `pip install numpy==2.1.3`
- **opencv-python** – `pip install opencv-python==4.10.0.84`

## Automation & Browsing
- **selenium** – `pip install selenium==4.25.0`

## Standard Library (already included, no installation needed)
- `json`, `subprocess`, `os`, `time`, `webbrowser`, `re`, `datetime`, `threading`
